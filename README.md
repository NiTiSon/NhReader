# Nh Reader
Unofficial android nhentai.net client on. Written on Flutter. Proposals are welcomed.

## Bug reports
Go to [this link](https://github.com/NiTiSon/NhReader/issues/new) to make new issue.

## Development

To build this project you need to install [Flutter SDK](https://docs.flutter.dev/install).

## Apk files
Run this command to build apk files.
```sh
flutter build apk
```

## Run
Attach your physical device in debug mode via Wi-Fi or USB.

Run this command to debug this application
```
flutter run --debug
```
